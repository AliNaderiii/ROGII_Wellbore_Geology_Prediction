# synthetic_geoanchor/ — GeoAnchor controlled experiment (arms A–E)

> ⚠️ **SYNTHETIC PIPELINE VERIFICATION ONLY — NOT A REAL KAGGLE COMPETITION RESULT.**
> Every `synthetic_geoanchor_*` file in this directory was produced against a
> **synthetic field** generated by `scripts/make_synthetic_field.py`
> (240 train wells, seed 0). The real competition data was not mounted in this
> environment, so these numbers verify that the harness runs and that the
> pre-registered decision machinery works end to end. They must **never** be
> quoted as validation results for the ROGII Wellbore Geology Prediction
> competition.

## Provenance

```bash
python scripts/make_synthetic_field.py --root <synthetic_root> --n-train 240 --seed 0
ROGII_COMPETITION_ROOT=<synthetic_root> \
ROGII_REPORTS_DIR=reports/synthetic_geoanchor \
python scripts/run_geoanchor_experiment.py --n-splits 5 --n-bootstrap 2000 --label synthetic-240
```

Pre-registration: `reports/geoanchor_experiment.md` (arms, gate rules,
decision rule, forbidden list). Implementation: `src/geoanchor.py`,
`src/geoanchor_reporting.py`. Tests: `tests/test_geoanchor_experiment.py`.

File naming is evidence-based: `real_geoanchor_*` would be written only when
discovery finds the audited real mount (773 train wells / 770 eligible after
blocking the three public test well IDs). This run discovered 240/240, so the
`synthetic_` prefix and banner stamp were applied automatically by
`src/real_ablation_reporting.py`. **No final submission was created.**

## Synthetic-specific caveats

- The synthetic field's GR/typewell generator does **not** reproduce the real
  competition's noise, calibration, or marker structure, so arm-level deltas
  here say nothing about real-data performance.
- On this synthetic field, every arm is **NOT_CARRIED** under the
  pre-registered rule; Ridge Default remains the anchor and the fallback.
- Arm E's gate passed its OOF kill switch (pooled OOF delta ≈ −0.8…−1.0) yet
  degraded the validation tail (worst-10 RMSE +4.9 / +2.9) — a demonstration
  that the gate machinery executes faithfully and that synthetic OOF
  improvements do not imply tail safety. This is a harness-fidelity finding,
  not evidence about the real competition.
