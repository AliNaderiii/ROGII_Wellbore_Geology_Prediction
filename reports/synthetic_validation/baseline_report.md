## 10. Leakage controls in force

| Control | Mechanism |
|---|---|
| TVT never a feature | Models receive `InferenceTask`, which has no target attribute |
| TVT_input never read past the boundary | NaN from `start` onward; `assert_no_target()` verifies |
| Train-only markers rejected | `assert_safe_features` raises on ANCC/ASTNL/ASTNU/BUDA/EGFDL/EGFDU |
| Unaudited columns rejected | The manifest is a whitelist, not a blacklist |
| Public test wells excluded | `assert_no_blocked_wells` at universe, fold, fit, donor and results |
| Wells never span folds | `GroupKFold` by well ID |
| No model fitted on a well it scores | Both protocols run through `run_cross_fitted_protocol`, which raises `CrossFitLeakage` on any train/validation overlap |
| In-sample results cannot be mistaken for validation | Diagnostic is named `INVALID_in_sample` and excluded from ranking and stratified tables |
| Spatial features fold-safe | Prior rebuilt per fold from fold-train donors; self excluded by ID |
